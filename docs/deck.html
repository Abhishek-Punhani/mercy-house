Reward proof, not a lucky name

R = clamp(C − 0.20 F − 0.10 U, 0, 1)

C: supported target coverage. F: distinct false findings. U: distinct unsupported findings.

Physical mechanisms and testimony must agree. Paper ownership alone cannot establish forgery. An unsupported correct guess earns zero.

Narrative is retained but unscored. Programmatic authored proof paths; no LLM judge.
